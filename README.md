# 💰 אפליקציה לניהול הכנסות והוצאות

אפליקציה פשוטה ויעילה לניהול הכנסות והוצאות חודשי, בעברית ועם ממשק ידידותי למשתמש.

## ✨ תכונות עיקריות

- **ניהול חודשי** - מעקב אחר הכנסות והוצאות לפי חודשים
- **ניווט בין חודשים** - מעבר קל בין חודשים שונים
- **הכנסות והוצאות**:
  - סימון פריטים עם checkbox
  - חישוב אוטומטי של הסכום הכולל
  - הוספת פריטים חד פעמיים (לחודש ספציפי)
  - הוספת פריטים קבועים בסכום קבוע (חוזרים כל חודש באותו סכום)
  - **🆕 הוספת פריטים קבועים בסכום משתנה** - סכום שמשתנה מחודש לחודש
  - **🆕 תתי-פריטים** - יצירת הכנסות/הוצאות מורכבות (לדוגמה: השכרת דירות עם מספר דירות)
- **חישוב יתרה** - הצגת היתרה החודשית (הכנסות פחות הוצאות)
- **שמירת נתונים** - כל הנתונים נשמרים ב-localStorage של הדפדפן
- **עיצוב מודרני** - ממשק משתמש מרהיב עם אנימציות חלקות

## 🚀 התקנה והפעלה

האפליקציה לא דורשת התקנה! פשוט פתח את הקובץ `index.html` בדפדפן.

### אופציה 1: פתיחה ישירה
1. הורד את כל הקבצים לתיקייה אחת
2. לחץ פעמיים על `index.html`
3. האפליקציה תיפתח בדפדפן

### אופציה 2: שרת מקומי (מומלץ)
```bash
# אם יש לך Python מותקן:
python -m http.server 8000

# או עם Node.js:
npx http-server

# פתח דפדפן בכתובת:
# http://localhost:8000
```

## 📖 הוראות שימוש

### הוספת הכנסה או הוצאה

1. לחץ על כפתור "הוסף הכנסה" או "הוסף הוצאה"
2. מלא את הפרטים:
   - **שם** - תיאור ההכנסה/הוצאה (לדוגמה: "משכורת", "שכר דירה")
   - **סכום** - הסכום בשקלים (למעט פריטים קבועים משתנים - ראה להלן)
   - **סוג**:
     - **חד פעמי** - יופיע רק בחודש הנבחר
     - **קבוע - סכום קבוע** - יופיע בכל חודש אוטומטית באותו סכום
     - **קבוע - סכום משתנה** - יופיע בכל חודש, אך הסכום יכול להשתנות מחודש לחודש
   - **חודש** - (רק לפריטים חד פעמיים) בחר את החודש הרלוונטי
   - **פריט עם תתי-פריטים** - (רק לפריטים קבועים) סמן אם ברצונך להוסיף תתי-פריטים
3. לחץ "שמור"

### 🆕 שימוש בתתי-פריטים

תתי-פריטים מאפשרים לך לנהל הכנסות או הוצאות מורכבות. לדוגמה:
- **השכרת דירות** - כל דירה היא תת-פריט נפרד
- **הכנסות עצמאי** - כל לקוח או פרויקט הוא תת-פריט
- **הוצאות רכב** - דלק, ביטוח, תחזוקה כתתי-פריטים

**כיצד להשתמש:**
1. בעת יצירת הכנסה/הוצאה, בחר סוג "קבוע - סכום קבוע" או "קבוע - סכום משתנה"
2. סמן את התיבה "פריט עם תתי-פריטים"
3. לאחר שמירת הפריט, יפתח חלון לניהול תתי-פריטים
4. הוסף תתי-פריטים עם שם וסכום לכל אחד
5. הסכום הכולל של הפריט יחושב אוטומטית מסכום התתי-פריטים

**ניהול תתי-פריטים קיימים:**
- לחץ על כפתור "ניהול תתי-פריטים" ליד הפריט
- הוסף, מחק או ערוך תתי-פריטים
- סמן/בטל סימון של תתי-פריטים בודדים

### 🆕 שימוש בסכום משתנה

פריטים קבועים עם סכום משתנה מאפשרים לך להגדיר סכום שונה לכל חודש. לדוגמה:
- **שכר עבודה משתנה** - משכורת שמשתנה בהתאם לשעות או בונוסים
- **חשמל/מים** - הוצאות שמשתנות מחודש לחודש
- **הכנסות עצמאי** - הכנסה שמשתנה מחודש לחודש

**כיצד להשתמש:**
1. צור פריט חדש עם סוג "קבוע - סכום משתנה"
2. הפריט יופיע בכל חודש עם סכום 0 כברירת מחדל
3. לחץ על כפתור "עדכן סכום" ליד הפריט
4. הזן את הסכום עבור החודש הנוכחי
5. הסכום יישמר עבור החודש הספציפי בלבד

### סימון פריטים

- לחץ על ה-checkbox ליד כל פריט כדי לסמן/לבטל סימון
- רק פריטים מסומנים נכללים בחישוב הסכום הכולל
- זה שימושי למקרים בהם הכנסה או הוצאה עדיין לא התקבלה/שולמה

### מחיקת פריטים

- לחץ על כפתור "מחק" ליד הפריט
- יופיע חלון אישור לפני המחיקה

### ניווט בין חודשים

- השתמש בחצים (◄ ►) למעבר בין חודשים
- הכנסות והוצאות קבועות יופיעו אוטומטית בכל חודש
- פריטים חד פעמיים יופיעו רק בחודש שנבחר עבורם
